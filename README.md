# CLinical Trial Supply Data Quality
## Overview

This project demonstrates an Excel-based approach to assessing, cleaning, and validating synthetic clinical trial supply data.

The dataset represents shipment records and contains deliberately introduced data-quality issues, including inconsistent formats, missing values, and potentially anomalous records.

## Objectives

- Identify missing, inconsistent, and potentially invalid data.
- Investigate anomalies before making changes.
- Apply documented data-cleaning rules.
- Validate the cleaned dataset.
- Communicate findings and limitations clearly.

## Tools

- Microsoft Excel
- Git and GitHub
- Visual Studio Code

## Dataset

The project uses a synthetic clinical trial supply dataset created for practice and demonstration purposes. It contains no real clinical trial or patient data.

The original dataset is preserved as the source of truth. Any cleaned outputs and transformation decisions will be documented separately.

## Workflow

1. Profile the source data.
2. Identify and investigate data-quality issues.
3. Document findings and proposed corrections.
4. Clean the data using justified, documented rules.
5. Validate the cleaned output.
6. Summarize results, limitations, and recommendations.
